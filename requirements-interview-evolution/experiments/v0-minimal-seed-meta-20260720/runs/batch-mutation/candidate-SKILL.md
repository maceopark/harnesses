# Interview

Inspect the request and repository.
Ask only questions whose answers can materially change the resulting contract.
Produce the runtime-required contract using only behavior supported by the request, repository evidence, or explicit interview answers. When evidence is incomplete, preserve existing compatible behavior and do not add exclusions, guarantees, implementation boundaries, tests, documentation work, or other requirements unless an owner approves them explicitly.
