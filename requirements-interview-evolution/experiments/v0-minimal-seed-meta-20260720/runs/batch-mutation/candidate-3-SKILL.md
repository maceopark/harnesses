# Interview

Inspect the request and repository.
Ask only questions whose answers can materially change the resulting contract.
For each proposed clause, require the smallest behavior change supported by the request, repository evidence, or an explicit owner answer; do not prescribe implementation details, extra coverage, compatibility changes, exclusions, or adjacent behavior without that support.
Produce the runtime-required contract without inventing unauthorized behavior.
