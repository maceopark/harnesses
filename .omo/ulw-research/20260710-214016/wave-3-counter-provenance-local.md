# Wave 3 — Provenance Specs vs Local Runtime

- Current enforced: selected local schema/lineage/internal digest and revision coherence.
- Current declarative/bypassable: actor/channel provenance, independence group, freshness, reviewer/authority identity.
- Absent: complete snapshot manifest, external durable head, rollback/equivocation protection, policy rotation, executed verification receipt, universal file/session coverage.
- Proposed conditionally: verifier-derived provenance/failure domains, exact snapshot binding, monotonic head, expiry/authority epochs, old+new rotation, external checkpoint, sandboxed execution receipts.
- Core verdict: current gates prove selected local structural coherence, not authenticated provenance, trusted freshness, rollback resistance, or execution proof.
